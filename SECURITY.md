# Security and local data

The application operates on local recordings. Treat unfamiliar recording files as untrusted input and keep Python and its native dependencies maintained. Do not upload private recordings or diagnostic paths to a public issue.

Report a suspected vulnerability privately to shashi.18j@gmail.com with the version and a minimal reproducer. There is no established response-time commitment or formal security audit for this research release.

Release checksums identify the supplied bytes. The Mac package is ad-hoc signed and not Apple notarized; a checksum or an ad-hoc signature does not establish developer identity. Source code and rebuild instructions are provided for inspection.
