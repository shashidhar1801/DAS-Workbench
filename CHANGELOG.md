# Release history

## 0.3.4.post1 public distribution preparation

- Added an illustrated user guide, manuscript recipes, dataset citations, source/build instructions and scoped validation documentation.
- Updated version/About information for the public distribution package.
- Removed the unused Qt virtual-keyboard runtime from the packaged application. Added Qt and PySide licence texts and corresponding-source directions.
- Preserved the scientific kernels, native readers, timing/quantity contracts, spectral checkpoint/resume and saved-result formats of v0.3.4.
- Kept historical example bundles and screenshot provenance unchanged. A new package does not convert historical evidence into a new experiment.

## 0.3.4 maintenance

Corrected timezone qualification for native aware timestamps, improved phase-workspace error details and recovery, and clarified what exported bundles retain. Scientific calculations were unchanged.

## 0.3.3 general use

Added researcher-facing recording selection, timestamp handling, bounded planning, diagnostic presentation and the general-use workflow. The four source-associated case examples were exercised through author-run packaged-GUI workflows.

## Earlier milestones

The v0.3.0 public-event milestone introduced native readers and quantity-aware case workflows. Subsequent publication-readiness work added presentation, provenance and repeatability evidence. Earlier OOI milestones established streaming full-fibre overviews and checked spectral checkpoint/resume. Historical reports are retained by the maintainer; this repository is a clean source distribution rather than a fabricated historical Git history.
